# ansumanshah/skills

Public skills for coding agents. Every file here ships to strangers.

- `skills/<name>/SKILL.md`: one folder per skill; `name` must match the folder.
- Add `plugins/`, `tools/` or `connectors/` only when something in them can be installed by a stranger.
- `scripts/check.ts`: run `bun scripts/check.ts` before every commit.

Rules: no absolute home paths or private project names. Publish only what you wrote, or keep the original license and credit. Commits: `<type>: <description>`.
